# Desafio de colaboração no GitHub

Bem-vindo à wiki deste repositório criado para praticar recursos de colaboração no GitHub como parte do curso da DIO.me.

## Objetivo

Praticar os recursos de colaboração do GitHub usando minhas próprias contas, com Issues, branches e Pull Requests.

## Atividades

- [ ] Adicionar minha outra conta como colaboradora do repositório.
- [ ] Criar uma Issue para registrar uma tarefa.
- [ ] Fazer uma alteração em uma branch e abrir um Pull Request.
- [ ] Revisar e integrar o Pull Request; encerrar a Issue relacionada.

## Sobre

Este repositório tem finalidade educacional e serve para praticar as ferramentas de colaboração disponíveis no GitHub.

Como usar esta wiki

- Esta página `Home` é a principal da wiki do repositório. Você pode editar diretamente no GitHub (opção "Edit this page") ou clonar o repositório wiki em `https://github.com/andrewgadelha0/repositorio-para-testar-colaboracoes.wiki.git` e trabalhar localmente.
- Crie novas páginas na pasta `wiki/` deste repositório para manter o conteúdo versionado junto com o código, ou atualize a wiki real via a interface "Pages" > "Wiki" no GitHub.
